# Announcing adash.ahk v0.2.0 – Packed with Powerful New Features!

We’re excited to announce the release of *adash.ahk* v0.2.0! This update brings a range of new methods that will make working with AutoHotkey more efficient and enjoyable. Whether you're handling strings, numbers, or complex data structures, the latest version of *adash.ahk* is here to simplify your coding experience even further.

### What’s New in v0.2.0:

This version introduces an array of string manipulation functions that allow for more control and flexibility in your scripts. Here’s a quick rundown of the new methods:

- **String Manipulation Made Easy**: 
  - `includes`, `endsWith`, `startsWith` – Quickly check if your strings contain, start, or end with specific values.
  - `pad`, `padEnd`, `padStart` – Add padding to your strings effortlessly.
  - `trim`, `trimEnd`, `trimStart` – Clean up your strings by removing unwanted whitespace.
  - `repeat`, `truncate` – Control string length and repetition with ease.
  - `toLower`, `toUpper`, `lowerFirst`, `upperFirst` – Effortlessly transform string cases.
  - `escape`, `unescape` – Manage special characters with robust escaping methods.
  - `words` – Split strings into words like a pro!

- **Util Methods**: 
  - `identity` – A simple utility for returning the value passed, useful in advances function chains.

- **Other Goodies**:
  - `first` – Instantly grab the first element from arrays for quick access.
  - `toString`, `typeof`, `parseInt` – Handy methods to convert, identify, and handle data types.
