# adash.ahk v0.3.0 – Packed with New Features and Performance Boosts!

We’re thrilled to be publishing adash.ahk v0.3.0 today! This release is filled with powerful new methods and some serious performance upgrades that will take your AutoHotkey scripting to new heights. Here’s what you can expect:

### New Features:

- **Sampling & Shuffling**: 
  - `.sample` – Quickly grab a random element from an array.
  - `.shuffle` – Mix things up by shuffling the elements in your array!

- **Math Methods**:
  - Perform a wide range of mathematical operations with these new methods:
    - `.add`, `.ceil`, `.divide`, `.floor`, `.max`, `.mean`, `.min`, `.multiply`, `.round`, `.subtract`, `.sum`

### Case Insensitivity by Default:
Starting with v0.3.0, *adash.ahk* will now handle string comparisons in a **case-insensitive** manner by default. This makes working with strings even easier. However, if you prefer case-sensitive handling, you can simply switch this feature off by setting:

```autohotkey
_.stringCaseSense := true
```

### Performance Boosts:
We’ve also made some fantastic changes to the performance of the `.map` method. Now faster and more efficient.

### Guarded Methods:
The following methods are now optimized for use within `.map`:
- `.trimEnd`, `.trimStart`, `parseInt`, `.chunk`, `.take`, `.takeRight`, `.drop`, `.sampleSize`, `.words`, `.random`

The following native functions are now fully compatible with `.map`:
- `Trim`, `LTrim`, `RTrim`, `StrLen`


### Bug Fixes:
- **.cloneDeep**: Now works better with array values, ensuring more reliable deep cloning.
- **.random**: Will return a float when both lower and upper bounds are set to 1, next time you need a quick value between 0 and 1.

---

Here’s a some new awesome stuff you can now perform with `.random`:

```autohotkey
_.map([true, true, true], _.random)
; => [0.42249310922182098, 0.74585438002008186, 0.80905787852214506]

_.random(true)
; => 0.020177190535065948

_.map([0, 10, 100], _.random)
; => [1, 4, 9]
```
