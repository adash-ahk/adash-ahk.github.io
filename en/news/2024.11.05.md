## Filter Out the Noise with .compact

Time to highlight another handy **adash.ahk** method: `.compact`! This method helps you cut out the clutter in your arrays by removing any *falsey* values (`false`, `0`, `""`, and `unset`). This keeps your arrays lean and focused, making it a go-to method when you want clean data.

`.compact` is immutable. Your original array stays intact, while the new, cleaned-up array gives you a fresh start. 

### Example 1: Removing Blank Lines from a File

How many times have you parsed a file and run into blank lines scattered throughout? `.compact` can help you quickly remove these blank entries, so only lines with content remain.

```autohotkey
fileLines := ["Line 1", "", "Line 2", "", "Line 3"]
nonEmptyLines := _.compact(fileLines)
; => ["Line 1", "Line 2", "Line 3"]
```

Now, only the meaningful data remains, making it ready for display or further processing.


### Example 2: Cleaning Up Inventory Orders

In an inventory system, users might remove or delete items from their order list, leaving empty slots. Using `.compact`, you can quickly clear out these blanks and focus the list on available items. Even though **adash.ahk** is immutable, we can overwrite the original variable here if preferred.

```autohotkey
orderItems := ["Laptop", "", "Mouse", "", "Keyboard", "Monitor", ""]
orderItems := _.compact(orderItems)
; => ["Laptop", "Mouse", "Keyboard", "Monitor"]
```

Now the list displays only in-stock items, keeping inventory records clean and accurate.
