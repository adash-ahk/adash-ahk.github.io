# adash.ahk v0.4.0 is here!

New features, blazing-fast performance, and smarter error handling.

### New Functionality
- **`.indexOf`** now works seamlessly with string input!
- **`.take`** is also string-friendly, making it easier to slice and dice your data.
- **New Methods**:
  - **`.unzip`** for quick array unbundling.
  - **`.some`** for easy condition checking.
  - **`.isMap`** to detect maps.
  - **`.isEmpty`** for checking if an object, array, or map is empty.
  - **`.inRange`** for bounds-checking made simple.

### Performance Boosts
- **`.min`** and **`.max`** are now turbo-charged, making them much faster.
- We’ve flipped the **type checking system** on its head! Now, if you set `_.throwExceptions := false`, adash.ahk will skip the type-checking process altogether; giving you pure speed when you need it most.
  - This is a massive update!
  - Expect significant performance improvements across the board!

### Smarter Error Messages
- We've improved type error messages. Not that you would ever make a mistake—because, let’s face it, adash.ahk is so easy to use! But on the off chance something does go wrong, with `_.throwExceptions := true`, you'll get clearer error messages, showing you exactly what data type was expected versus what was received.

### Overall Speed Improvements
- Thanks to these updates, most methods in adash.ahk are now faster, leaner, and ready to handle more intensive workloads.

---

This version is all about speed, flexibility, and making your life easier. Enjoy the faster, smarter adash.ahk!
