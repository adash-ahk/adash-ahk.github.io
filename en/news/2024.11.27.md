## Splitting Arrays with Style: The .head and .tail Combo

Navigating arrays often involves focusing on their boundaries: the first element and everything else that follows. With adash.ahk's `.head` and `.tail`, you can easily grab the start and the rest of an array. This duo simplifies tasks where the beginning and remaining parts need special attention.

- **`.head`** (alias `.first`) extracts the first element of an array.
- **`.tail`** returns everything but the first element.

Both are immutable, meaning they leave the original array untouched.

### Example 1: Getting the First Element and the Rest

Suppose you're processing a list of race results and want to separate the winner from the rest of the participants.

```autohotkey
raceResults := ["Logos", "Novalis", "Osiris", "Mjolnir"]

winner := _.head(raceResults)
; => "Logos"
others := _.tail(raceResults)
; => ["Novalis", "Osiris", "Mjolnir"]
```

With `.head`, you can grab the winner, while `.tail` ensures you handle the rest effortlessly.

### Example 2: Advanced Array Transformation with .map

Let’s up the ante with a more advanced example: processing a collection of nested arrays using `.map`, `.head`, and `.tail`. Imagine you're working with a dataset where each entry includes a leader followed by a group of team members, and you want to create a summary.

```autohotkey
teams := [["Morpheus", "Switch", "Cypher"], ["Niobe", "Ghost", "Sparks"], ["Roland", "Mauser"]]

summaries := _.map(teams, (team) => {leader: _.head(team), members: _.tail(team)})
; => [{leader: "Morpheus", members: ["Switch", "Cypher"]}
;	, {leader: "Niobe", members: ["Ghost", "Sparks"]},
;	, {leader: "Roland", members: ["Mauser"]}]
```

Here, `.map` iterates over each team, while `.head` and `.tail` split the leader from the members. This is a clean, readable way to process hierarchical data.

---

### A Perfect Pair for Array Work

`.head` and `.tail` are a natural pair, providing simple yet powerful tools for handling arrays' first elements and the rest. Together, they make complex array manipulations more intuitive. What else could you accomplish with these methods? You aren't limited to array input; `.head` and `.tail` are also compatible with string and object input.

```autohotkey
_.head("Neo")
; => "N"
```
