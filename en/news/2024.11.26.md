## Unpacking Data with .flatten and .flattenDeep

Working with nested arrays can sometimes feel like untangling a web. That’s where adash.ahk `.flatten` method comes in! It simplifies your data by flattening one level of nested arrays, leaving the rest untouched. If your data goes deeper, consider `.flattenDeep` for unraveling deeply nested arrays in one go.

Both `.flatten` and `.flattenDeep` are non-mutating, meaning they create a new array without altering the original, so your data remains safe and sound.


### Example 1: Flattening a Nested Array

Suppose you have an array containing numbers and nested arrays, and you want to bring everything to the top level—but only one level deep.

```autohotkey
nested := [1, 2, [3, 4], [5, [6]]]
result := _.flatten(nested)
; => [1, 2, 3, 4, 5, [6]]
```

In this example, `.flatten` removes the first level of nesting, leaving `[6]` untouched since it’s nested deeper.


### Example 2: Flattening API Response Data

Imagine you’re working with a list of items fetched from an API, where each item has a varying structure. Some items have sub-items stored in nested arrays, and you need to process them in a uniform way. You can use `.flattenDeep` to turn that nested data into a single-level array that’s much easier to work with.

```autohotkey
apiResponse := [{id: 1, name: "Item 1", details: ["Detail 1", "Detail 2"]}
	, {id: 2, name: "Item 2", details: ["Detail 3", ["Sub-detail 1", "Sub-detail 2"]]}
	, {id: 3, name: "Item 3", details: ["Detail 4"]}]

flattenedDetails := _.flattenDeep(_.map(apiResponse, (item) => item.details))
; => ["Detail 1", "Detail 2", "Detail 3", "Sub-detail 1", "Sub-detail 2", "Detail 4"]
```

In this example, the API response contains a mix of simple and deeply nested arrays in the `details` field. By using `.flattenDeep`, you can transform all of these details into a single array of strings, making it easier to display or process further.
