# adash.ahk v0.7.0: Bigger Toolkit, Cleaner Fixes

We're excited to publish **v0.7.0**, the biggest release yet. It adds a wide set of new methods for sorting, finding, mapping, and string casing, plus fixes that make existing methods behave the way you'd expect.

- **Utilities:** `.times`, `.toPath`, `.property`, `.matches`, `.matchesProperty`, `.constant`
- **Language:** `.isError`, `.isNative`
- **Object:** `.get` and `.set`

### Function Control: .once, .after, and .before
Wrap any function so it runs on a schedule you control. These three methods return a new function, so you can drop them straight into callbacks or event handlers.

- **`.once`:** Runs the function on the first call only. Later calls return the first result.
- **`.after`:** Stays silent until it has been called `n` times, then runs on every call after that.
- **`.before`:** Runs the function until it has been called `n` times, then keeps returning the last result.

```autohotkey
; .once: first call runs, later calls reuse the result
greet := _.once((name) => "Hello " name)
greet("Neo")       ; => "Hello Neo"
greet("Trinity")   ; => "Hello Neo"

; .after: nothing happens until the third call
ready := _.after(3, (name) => "All systems go, " name)
ready("Neo")       ; => ""
ready("Neo")       ; => ""
ready("Neo")       ; => "All systems go, Neo"

; .before: runs twice, then holds the last result
counter := 0
limited := _.before(3, () => ++counter)
limited()          ; => 1
limited()          ; => 2
limited()          ; => 2
```

### Fixes for Better Consistency and Accuracy

- **`.without`:** Fixed an operator-precedence bug in the removal loop that could leave wrong values behind. It now shares its matching logic with `.pull` and never mutates the input array.

### .sortBy and .times
Sorting and generating data are two of the most common chores in a script. With `.sortBy` and `.times`, both become one-liners.

- **`.sortBy`:** Sort a collection by a property name, a list of property names, or a function.
- **`.times`:** Build an array by calling an iteratee `n` times. Pair it with `.constant` to repeat a fixed value.

```autohotkey
users := [{name: "tank", age: 40}
	, {name: "cypher", age: 36}
	, {name: "cypher", age: 34}]

; Sort by age
sorted := _.sortBy(users, "age")
; => [{name: "cypher", age: 34}, {name: "cypher", age: 36}, {name: "tank", age: 40}]

; Sort by name, then age
sorted := _.sortBy(users, ["name", "age"])
; => [{name: "cypher", age: 34}, {name: "cypher", age: 36}, {name: "tank", age: 40}]

; Generate four zeros
zeros := _.times(4, _.constant(0))
; => [0, 0, 0, 0]

; Convert to kebab-case
slug := _.kebabCase("fooBar")
; => "foo-bar"
```
