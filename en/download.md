# Download adash.ahk

adash.ahk is hosted on GitHub and npm. Pick whichever suits you:

<a href="https://github.com/adash-ahk/adash.ahk/releases" target="_blank" rel="noopener"><button class="btn"><i class="fab fa-github"></i> GitHub Releases</button></a>
<a href="https://www.npmjs.com/package/adash.ahk" target="_blank" rel="noopener"><button class="btn"><i class="fab fa-npm"></i> npm</button></a>

## GitHub

Download the latest `adash.ahk` from the [Releases page](https://github.com/adash-ahk/adash.ahk/releases) and place it in your script's `Lib` folder, or `#Include` it directly.

## npm

```
npm install adash.ahk
```

See [Getting Started](/en/getting-started) for how to include it in your script.
