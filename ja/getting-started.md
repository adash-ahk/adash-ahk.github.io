## インストール

コードに含める必要があるのは adash.ahk ファイルだけです:

```autohotkey
#Include <adash.ahk>

_ := adash
msgbox(_.join(["a", "b", "c"], " "))
; => "a b c"
```

### プロパティ

デフォルトでは、次のプロパティが設定されています:

`_.throwExceptions := true`
型に関するエラーを検出できる箇所では、adash.ahk はエラーが発生した場所を示す例外をスローします。例外でスクリプトを止めたくない場合は、これを `false` に設定してください。

`_.stringCaseSense := false`
文字列の比較は既定で大文字小文字を区別しません。区別したい場合は、これを `true` に設定してください。オブジェクトやマップのキーの照合にも適用されます。
