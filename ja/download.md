# adash.ahk をダウンロード

adash.ahk は GitHub と npm で公開されています。お好きな方をご利用ください:

<a href="https://github.com/adash-ahk/adash.ahk/releases" target="_blank" rel="noopener"><button class="btn"><i class="fab fa-github"></i> GitHub Releases</button></a>
<a href="https://www.npmjs.com/package/adash.ahk" target="_blank" rel="noopener"><button class="btn"><i class="fab fa-npm"></i> npm</button></a>

## GitHub

[Releases ページ](https://github.com/adash-ahk/adash.ahk/releases)から最新の `adash.ahk` をダウンロードし、スクリプトの `Lib` フォルダに置くか、直接 `#Include` してください。

## npm

```
npm install adash.ahk
```

スクリプトへの読み込み方法は[はじめに](/ja/getting-started)をご覧ください。
